# Sales KPI Dashboard & Analysis

## Project Overview
This project analyzes sales data and presents key business insights using SQL, Excel, and Power BI.

## Tools Used
- Excel
- SQL (MySQL)
- Power BI
- Data Analysis

## Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Sales by Region
- Sales by Category
- Monthly Sales Trend
- Top Products by Sales
- Region Filter

## SQL Analysis
The project includes SQL queries using:
- Aggregations
- GROUP BY
- ORDER BY
- CTE
- Window Functions
- Date-based analysis

## Files
- `sales_data.xlsx` – Sales dataset
- `sales_analysis.sql` – SQL queries and analysis
- `Sales_KPI_Dashboard.pbix` – Power BI dashboard

## Objective
To analyze sales performance and present business insights through an interactive Power BI dashboard.
